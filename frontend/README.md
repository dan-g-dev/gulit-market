# Gulit Market ጉሊት ገበያ

Ethiopia's premier modern marketplace for fashion, handwoven Habesha Kemis, specialty coffee, artisanal home crafts, and vintage goods — with Telebirr and global checkout.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
